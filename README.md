# 個人資產總帳 (Wealth Ledger)

一個輕量、本機優先的個人理財與資產管理 Web App，整合**台／美／港股、跨幣別銀行現金、實體投資、固定收入、支出紀錄與外幣交易**，並透過 **Cloudflare Workers** 提供即時股價與匯率查詢 API，支援 PWA 安裝、JSON / Excel 備份，以及可選的 Firebase 雲端同步。

---

## 主要功能

### 資產管理與儀表板
- **今日任務與總覽儀表板**：一眼掌握總淨資產、資產成長趨勢線圖、資產配置比例與各幣別曝險分佈。
- **股票與 ETF**：支援 **台股（上市 / 上櫃）**、**美股**、**港股** 持倉管理，可即時更新股價，也支援批次手動調價與 Google 試算表 CSV 備援報價。
- **銀行現金**：管理多幣別存款帳戶，自動依即時匯率換算為新台幣（TWD）。
- **實體投資**：追蹤房地產、貴金屬或其他非證券類實體投資項目。

### 現金流與歷史追蹤
- **固定收入與支出紀錄**：記錄每月固定收入與日常／不定期支出。
- **外幣交易**：記錄換匯明細與成本。
- **歷史紀錄與快照**：支援自動記錄每日淨資產快照，以圖表檢視長期資產變化趨勢。

### 隱私、備份與跨裝置同步
- **本機優先（Local-First）**：預設所有資料僅儲存在瀏覽器 `localStorage`，無需註冊帳號即可使用。
- **完整匯出與還原**：一鍵匯出／匯入 **JSON** 完整備份檔或 **Excel (`.xlsx`)** 報表。
- **可選雲端同步**：於「匯率與備份」頁面填入自己的 Firebase Config JSON，即可啟用 Google 登入與 Firestore 跨裝置同步。
- **PWA 支援**：內建 `manifest.json` 與 Service Worker，可加入手機或電腦主畫面作為獨立 App 使用。

## v1.5 新增功能

### 價格提醒（買進／停損／停利）
- 每檔持股可在「編輯持倉」設定**買進價、停損價、停利價**（留空代表不設定；買進價應高於停損價）。
- 每次報價更新（或手動改價）後自動比對：觸發時在持股列顯示徽章（買進價到／停損觸發／停利到價），並寫入持股頁的「🔔 價格提醒事件」清單（時間、代號、觸發類型、當時價格與觸發價）。
- 只在「未觸發 → 已觸發」的轉換當下記錄一次，不會重複洗版；回到安全區後狀態歸零，下次再觸發會重新記錄。**僅為提醒，不做任何自動交易。**
- 提醒價與提醒事件會隨 JSON 備份一起匯出匯入；Excel「股票持倉」工作表亦新增買進／停損／停利三欄。

### 策略化提醒價（芒格式）
- 每檔持股都有「提醒策略」：**芒格式（價值）**／Ted 趨勢／技術位／手動，預設為芒格式；策略會以徽章顯示在持股列（例如「芒格式」）。
- 芒格式的推導公式（在編輯表單即時計算）：
  - **建議買進價 ＝ 內在價值 ×（1 − 安全邊際）**，安全邊際預設 30%（可改，0–90%）；
  - **建議停利價 ＝ 內在價值**（漲到內在價值就不便宜了）；
  - **停損不用價格停損**：芒格式看基本面賣出，停損價預設隱藏，持股列顯示「停損：看基本面」，不發停損提醒、走勢圖也不畫停損線；如需硬性停損可勾選「另設硬性停損價（可選）」再填價。
- 芒格式的賣出條件（基本面變壞才賣）：護城河弱化、自由現金流轉負、負債失控、管理層誠信問題、出現更好機會，另可寫論述備註（為什麼值得買／什麼情況下會改變看法）。
- 點「套用建議價」會把算出的買進價與停利價填入提醒價欄位再儲存；提醒引擎本身不用改，仍比對買進／停損／停利三價。
- 策略、內在價值、安全邊際、賣出條件與論述備註都存在持股物件裡，隨 JSON 備份一起匯出匯入；舊備份或舊資料沒有策略欄位時，一律視為芒格式（安全邊際預設 30%）。
- Ted 趨勢／技術位／手動目前維持三個手動價格輸入，不做自動推導。

### 持股走勢圖（三條提醒線）
- 持股列新增「走勢」按鈕，開啟近 3 個月日收盤價走勢圖：收盤價曲線＋MA10／MA20／MA50＋EMA21，以及買進／停損／停利三條虛線（未設定買進價時只畫停損與停利線）。
- Y 軸範圍自動包含收盤價、均線與三條提醒價，不會把虛線裁掉；圖例直接標示各提醒價數值。走勢資料來自後端 `GET /api/history`。

### 報價透明度
- 每檔現價下方顯示報價來源（Yahoo／TWSE／試算表／Finnhub／手動）與報價所屬交易日；週末／假日明確顯示「休市中 · 最後收盤 MM/DD」，不再靜悄悄沿用舊價。
- 超過 6 小時未成功更新的報價顯示「舊資料」徽章；持股頁頂端亦顯示本次報價日。

### API Key 加密保險庫
- 設定頁新增金鑰保險庫：可設定加密密碼，將全部 API Key 以 **AES-GCM** 加密存放（PBKDF2 10 萬次迭代衍生金鑰，鹽值內嵌於密文，雲端同步副本亦為密文）。
- 密碼與衍生金鑰只保留於記憶體，關閉分頁即失效；忘記密碼將無法取回已加密的 Key，需重新申請。
- 舊版明文 Key 會顯示遷移橫幅，一鍵設定密碼完成遷移；之後新增的 Key（含 OpenRouter 一鍵授權）會自動加密存放。
- 加密密碼設定入口常駐顯示：即使是 0 組 Key，也能先設密碼再輸 Key；已設密碼但尚無加密 Key 時顯示「保險庫已就緒」。
- 「同步多組 API Key 至我的私人 Google 雲端」預設為**不勾選**（未設定過的使用者預設不同步）；已明確勾選過的使用者維持其選擇。
- 新增 **Key 健康度面板**（僅存本機）：每組 Key 的最後使用時間、成功／失敗次數、耗時、最後錯誤與最近自動切換紀錄。

### AI 供應商：NVIDIA / Kimi K3.1 Pro（新增）
- 設定頁「AI 供應商」新增 **NVIDIA / Kimi**：預設模型 `moonshotai/kimi-k3.1-pro`（Moonshot 2.8T 參數多模態模型，1M 上下文，支援圖片），走 OpenAI 相容格式，後端 Worker 代理到 `https://integrate.api.nvidia.com/v1`。
- Key 格式為 `nvapi-` 開頭，照現有流程加入輪替清單，可設加密密碼以 AES-GCM 加密存放；免費試用層約 40 RPM，僅適合測試。
- 預設供應商仍是 Groq，不變；NVIDIA 只是多一個可選項。設定方式：到「匯率與備份 → AI 模型設定」選 NVIDIA / Kimi，貼上自己在 [NVIDIA Build](https://build.nvidia.com/moonshotai/kimi-k3.1-pro) 申請的免費 Key，按「＋ 加入輪替清單」。

### 所在地與手頭現金
- 設定頁新增「所在地與手頭現金」：**當前所在地**（台灣／中國大陸／香港／美國／其他，預設台灣）與**手頭現金低額提醒門檻**（所在地幣別，預設 5000）。
- 所在地決定新增支出的預設幣別：台灣→TWD、中國大陸→CNY、香港→HKD、美國→USD、其他→TWD；扣款帳戶自動帶出該幣別的預設扣款帳戶，兩個下拉仍可手動改。固定支出新增也沿用同一規則。
- 現金帳戶新增「帳戶種類」：**銀行帳戶**／**手頭現金**（皮夾／家中現金，名稱自己填，例如「台灣現金」）；舊資料沒有種類欄位時一律視為銀行帳戶，不影響現有資料。
- **提領現金**：現金頁與總覽手頭現金卡都有「提領現金」按鈕，沿用帳戶轉帳機制把銀行存款搬到手頭現金錢包；搬錢不是支出，不產生支出紀錄、不計入花費統計（流水金額為 0）。
- 總覽頁新增「手頭現金」卡：顯示當前所在地的手頭現金餘額（該幣別手頭現金帳戶合計）、本月現金支出、剩餘現金（餘額－本月未扣款現金支出）；餘額低於門檻時顯示提醒，卡片上可直接切換所在地或提領現金。
- 非大陸地區時，CNY 帳戶不會被設為預設扣款帳戶（不排在前面、不標 ⭐）；CNY 帳戶本身不會被刪除或隱藏。
- 所在地與門檻隨 JSON 備份一起匯出匯入；Excel「銀行現金」工作表亦新增種類欄。

### 匯入預覽與清空保護
- JSON／Excel 匯入前先顯示預覽（各項目筆數與說明），確認後才寫入；匯入將完整覆蓋對應項目。
- 「清空帳本」改為：先自動下載一份 JSON 備份，再要求輸入「清空」兩字確認，避免誤觸。

### 收據辨識信心度
- AI 辨識收據／單據時會回傳每筆的信心度（0~100）；預覽表顯示信心度徽章，**信心度低於 60% 的項目預設不勾選**，需人工確認後才能匯入。
- 預覽表中的品項與金額可直接修改後再存檔。

### AI 助理與總覽圖表修復
- **照片上傳**：AI 助理、搬家、拍照批次、記帳照片四處上傳入口改用 `sr-only` 隱藏 file input（舊版 `display:none` 會讓 Chrome 忽略 label 點擊，點了沒反應）。同一個 bug 也出現在搬家頁 CSV／PDF 匯入與設定頁 JSON／Excel 匯入四處 label，順手一併改為 `sr-only`。
- **預設供應商一致**：AI 助理無 Key 時的預設候選與設定頁共用同一個預設（Groq，`AI_DEFAULT_PROVIDER`），不再一邊預設 Gemini、一邊預設 Groq；Gemini 預設模型為 `gemini-3.8-flash`（免費層）。
- **成長走勢圖**：淨值線以最近一筆快照向前延伸（圖例標示「最近快照」），快照稀疏時不再只剩一個點；淨值線加粗並顯示資料點；收支＋淨值雙軸加上「收支／淨值」軸標題；快照不足時副標題會提示曲線以最近快照延伸。
- **結構圓環對照**：圖例直接顯示各項佔比（例如「銀行與券商現金 53.0%」），不必再對照上方文字清單。
- **頂部雲端狀態文字**：未登入時顯示「尚未登入雲端」，不再與「待登入雲端」狀態自相矛盾。

## 內建 API 端點

由 `worker.js` 提供，預設套用 60 秒快取（`Cache-Control: public, max-age=60`）：

### 1. 查詢即時股價
```http
GET /api/quotes?items=TW:2330,US:AAPL,HK:0700
```
- **參數**：`items` 以逗號分隔，格式為 `市場:代號`（支援 `TW`、`US`、`HK`，省略市場前綴時預設為 `US`；單次上限 40 檔）。
- **回應範例**：
  ```json
  {
    "ok": true,
    "updatedAt": "2026-11-21T00:00:00.000Z",
    "prices": {
      "TW:2330": 1050,
      "US:AAPL": 228.5,
      "HK:0700": 410.2
    }
  }
  ```

### 2. 查詢即時匯率（對新台幣 TWD）
```http
GET /api/fx?currencies=USD,JPY,HKD,CNY
```
- **參數**：`currencies` 以逗號分隔的 3 碼 ISO 幣別代碼（預設 `USD,JPY,HKD,CNY`；單次上限 25 種幣別）。
- **回應範例**：
  ```json
  {
    "ok": true,
    "source": "yahoo",
    "updatedAt": "2026-11-21T00:00:00.000Z",
    "rates": {
      "USD": 32.5,
      "JPY": 0.215,
      "HKD": 4.18,
      "CNY": 4.52
    }
  }
  ```

### 3. 查詢即時股價（含來源與交易日）
`/api/quotes` 回應除 `prices` 外，另含 `meta`：每檔的報價來源（`yahoo`／`twse`）與報價所屬交易日（`marketDate`，`YYYY-MM-DD`），供前端顯示來源、舊資料徽章與休市提示。週末／假日回傳的仍為最後一個交易日的收盤價。

### 4. 查詢持股歷史走勢（近 3 個月日收盤價）
```http
GET /api/history?market=TW&symbol=2330
```
- **參數**：`market` 為 `TW`／`US`／`HK`，`symbol` 為股票代號。
- **回應範例**：
  ```json
  {
    "ok": true,
    "market": "TW",
    "symbol": "2330",
    "ticker": "2330.TW",
    "source": "yahoo",
    "dates": ["2026-08-26", "..."],
    "closes": [1050, "..."]
  }
  ```

## 本機開發與部署

### 環境需求
- Node.js 18+（用於執行 `npx wrangler`）
- Cloudflare 帳號（部署至 Cloudflare Workers 時需要）

### 本機預覽
```bash
npx wrangler dev
```
啟動後即可在瀏覽器開啟本機預覽網址，並同時測試 `/api/quotes` 與 `/api/fx`。

### 手動部署至 Cloudflare Workers
